## Gwan 키우기

능력치에 따라 여러 종류의 모습을 해금하고 자유롭게 변경이 가능한 Windows 전용 데스크톱 펫입니다.
우측 release에서 파일을 다운로드 해보실 수 있습니다.

### 주요 기능

- 화면 위를 자유롭게 돌아다니는 데스크톱 캐릭터
- 운동, 공부, 요리·음식, 경기 시청, 게임 능력치
- 능력치별 2단계 캐릭터 해금
- 최종 형태 달성 이후 모든 캐릭터 자유 전환
- 드래그 방식의 상호작용 오브젝트
- 진화체별 대사와 음악 추천
- Windows 시작 시 자동 실행 지원

### 실행 방법

1. ZIP 파일을 내려받습니다.
2. 원하는 폴더에 압축을 완전히 풉니다.
3. `EvolvingDesktopPet.exe` 또는 `실행하기.bat`을 실행합니다.

Windows SmartScreen 경고가 표시되면 파일 정보를 확인한 후 `추가 정보 → 실행`을 선택해주세요.
