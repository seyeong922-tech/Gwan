# 진화하는 데스크톱 펫

첨부 사진을 바탕으로 만든 Windows 전용 데스크톱 펫입니다. **관호 → 능력치별 2단계 분기 → 관종대왕** 순서로 진화합니다. 각 단계는 기본·걷기·말하기 외에도 표정·잠자기·뛰기·팔굽혀펴기·논문쓰기·춤추기를 반복하며, 마우스로 끌면 발버둥칩니다. 관이커에게는 전용 쉿 포즈가 있습니다.

## 실행

`EvolvingDesktopPet.exe`를 더블클릭하세요. 설치는 필요 없습니다.

- 왼쪽 클릭: 쓰다듬기
- 드래그: 원하는 위치로 이동
- 오른쪽 클릭: 상태, 아이템 즉시 생성, 대화 목록 새로고침, **오브젝트 드롭 방향**, **캐릭터 변경**, 음악 추천, 일시 정지, 시작 프로그램, 진행 기록 초기화, 종료

창이나 작업 표시줄에 버튼이 생기지 않는 것이 정상입니다. 종료하려면 캐릭터를 오른쪽 클릭하고 **종료**를 누르세요.

## 능력치와 분기 진화

- 능력치: 운동 / 공부 / 요리·음식 / 축구·야구 경기 시청 / 게임
- 2단계 분기명: 수원고 달리기 1등출신 / master in England / 관주부 / 관계인 / 관이커
- 각 능력치가 10에 도달하면 해당 방향의 2단계 캐릭터가 영구 해금됩니다.
- 처음 해금되는 2단계는 가장 높은 능력치 방향으로 진화 연출과 함께 자동 전환됩니다.
- 최고 수치가 동점이면 가장 최근에 올린 능력치가 진화 방향으로 선택됩니다.
- 운동 10, 게임 10처럼 여러 조건을 만족하면 우클릭 → **캐릭터 변경**에서 관호와 해금된 운동형·게임형을 자유롭게 오갈 수 있습니다.
- 다섯 능력치가 각각 20 이상이면 관종대왕으로 진화하며, 이후 관호·모든 2단계·관종대왕을 자유롭게 선택할 수 있습니다.
- 해금 기록은 영구 저장됩니다. 양상추로 현재 능력치가 감소하더라도 이미 해금한 캐릭터는 잠기지 않습니다.

진행 기록과 선택된 2단계 경로는 `%LOCALAPPDATA%\EvolvingDesktopPet\state.json`에 자동 저장됩니다. 우클릭 → **상태 보기**에서 오각형 능력치 차트를 확인할 수 있습니다.

## 조건 바꾸기

실행 파일 옆의 `settings.json`을 메모장으로 열어 숫자를 바꾸고 앱을 다시 실행하세요.

- `stage2_stat_threshold`: 각 2단계 캐릭터 해금에 필요한 해당 능력치
- `stage3_each_stat_threshold`: 3단계 진화에 필요한 각 능력치
- `sprite_height`: 화면에 표시될 캐릭터 높이
- `walk_speed`: 걷는 속도

JSON 문법이 깨지면 기본 설정으로 실행됩니다.

## 대사 추가하기

`dialogues.json`의 `1`, `3` 및 `2_exercise`, `2_study`, `2_food`, `2_sports`, `2_gaming` 목록에 큰따옴표로 감싼 대사를 추가하세요. 저장한 뒤 캐릭터를 우클릭하고 **대화 목록 다시 불러오기**를 누르면 앱을 재시작하지 않아도 적용됩니다.

- 관호: 아디다스 제품 홍보맨
- 수원고 달리기 1등출신: 달리기와 운동 중심
- master in England: 영국 석사와 공부 중심
- 관주부: 집밥과 요리 중심
- 관계인: 축구·야구 경기 시청과 아스날 응원 중심
- 관이커: 게임과 전략 중심
- 관종대왕: 두 성격이 합쳐진 완전체

`settings.json`의 `talk_interval_min_seconds`와 `talk_interval_max_seconds`로 혼잣말 간격을 조절할 수 있습니다. 말풍선은 짙은 남색 배경과 하늘색 글자로 표시됩니다.

## 상호작용 아이템

화면에 주기적으로 나타나는 아이템을 마우스로 끌어 캐릭터 위에 놓으세요. 아이템은 20초 후 사라지며 우클릭 → **상호작용 아이템 바로 생성**으로 즉시 시험할 수 있습니다.

우클릭 → **오브젝트 드롭 방향**에서 운동·공부·요리·경기 시청·게임 중 하나를 고르면 그 계열 오브젝트만 등장합니다. **자동 (모든 종류)**을 선택하면 기존처럼 전 종류가 등장합니다. 토마토와 수상한 양상추는 어떤 방향을 선택해도 공통으로 계속 등장합니다.

- 운동 +1: 아디다스 러닝화, 팔굽혀펴기 바
- 공부 +1: 논문, 링크드인
- 요리·음식 +1: 닭고기, 돼지고기, 토마토
- 무작위 능력치 -1: 수상한 양상추
- 경기 시청 +1: KT wiz 경기, Arsenal 경기
- 게임 +1: 롤토체스, 마인크래프트

진화할 때는 현재 모습과 다음 모습의 **검은 실루엣만** 점점 빠르게 교차한 뒤 진화한 캐릭터가 나타납니다. 이전의 하늘색 광원 효과는 제거했습니다.

아이템별 사용 횟수와 다섯 능력치는 저장 파일에 기록됩니다. 등장 간격과 수명은 `settings.json`의 `item_interval_min_seconds`, `item_interval_max_seconds`, `item_lifetime_seconds`로 조절합니다.

## 단계별 YouTube 추천곡

상호작용 아이템을 캐릭터에게 전달하면 현재 단계·진화 분기의 전용 후보군에서 직전에 추천한 곡을 제외하고 무작위로 한 곡을 고릅니다. 추천 제목은 캐릭터의 말풍선에 12초간 표시되며, **말풍선을 클릭했을 때만** 기본 브라우저의 YouTube 영상으로 이동합니다. 진화를 일으킨 상호작용에서는 진화 연출이 끝난 다음 새 진화체의 후보군에서 곡을 고릅니다.

- 1단계: `No Nike, Only Adidas`, `이관호, The Trendsetter` 등
- 운동: `체력왕 관호`, `나도 할 수 있어` 등
- 공부: `영국 가기 싫어`, `관호, 그가 걸어온 길` 등
- 요리: `관든램지`, `마라샹궈의 거부` 등
- 경기 시청: `KT의 열정`, `야구에 미쳐요` 등
- 게임: `한 판만 더 합시둥`, `정글의 희생` 등
- 관종대왕: `관종대왕`, `관무야 (refined)` 등

추천 풀은 제공된 두 YouTube 플레이리스트에서 현재 공개 재생 가능한 61곡 전체이며 `music.json`에서 제목, 영상 ID, 출처 플레이리스트를 수정할 수 있습니다. YouTube에서 숨긴 1개 영상은 제외했고, 같은 영상은 진화체 사이에 중복 배치하지 않았습니다.

우클릭 → **상호작용 음악 추천**으로 추천을 끄거나 켤 수 있고, **지금 음악 추천**으로 즉시 한 곡을 추천받을 수 있습니다. 곡을 듣지 않으려면 말풍선을 클릭하지 않고 그대로 두면 됩니다.

상호작용 오브젝트 창은 비활성 도구 창으로 생성되므로, 오브젝트가 나타나더라도 사용 중인 프로그램이나 브라우저 탭의 키보드 포커스를 가져오지 않습니다.

## 캐릭터 이미지 제작 메모

OpenAI 내장 이미지 생성 기능으로 각 사진의 얼굴과 의상 특징을 유지한 SD 게임 캐릭터를 만들고, 단계마다 표정 5종과 행동 포즈를 추가했습니다. 단색 크로마키 배경은 로컬에서 제거해 투명 PNG로 사용했습니다. 걷기는 두 원본 포즈를 약 0.55초, 뛰기·달리기의 팔 들기 전환은 약 0.65초씩 유지해 빠른 깜빡임을 줄였습니다.

잠자기 포즈는 다른 포즈보다 넓게 누워 보이는 점을 고려해 기본 캐릭터 높이의 62%로 별도 축소됩니다.
